# MouseLife Tracker — Frontend Dashboard

High-end, dark-mode glassmorphic React dashboard visualizing mouse click volume and hardware switch wear.

## Technologies
- React 19 + Vite
- Recharts (Interactive Volume Analytics & Button Ratios)
- Lucide React Icons
- Vanilla CSS Design System with custom glassmorphic tokens

## Running
```powershell
npm install
npm run dev
```
Open `http://localhost:5173`.
